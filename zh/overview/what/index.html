什么是 Dubbo

Apache Dubbo 是一款 RPC 微服务框架，提供了包括 Java、Golang 等在内的多种语言 SDK 实现。

  • 第一次接触 Dubbo，请继续阅读本章了解 Dubbo 提供的丰富功能及核心概念；
  • 想快速体验 Dubbo，请参考 快速开始
  • Dubbo3 高级用法参考 多语言 SDK 文档
